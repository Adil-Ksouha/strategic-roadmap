# Relationship Map Validation

The refreshed relationship-map preview shows newly created capabilities and Strategic Objectives as graph nodes and editor options without a manual page refresh. The map no longer limits its node set to the first six capabilities and first five Strategic Objectives.

The relationship-map header now includes an All domains selector with the five portfolio domains—Application Architecture, Core & Cloud, Data Architecture, Fixed & Transport, and Mobile Access—and a manual refresh action for immediate snapshot retrieval when needed.

The domain filter keeps every record owned by the selected domain visible, including standalone nodes with no relationship yet. It also preserves the direct cross-domain capabilities and Strategic Objectives linked to that domain, so dependency context is not lost when teams focus the map.

The Application Architecture filter was exercised in the live preview. It reduced the map to its owned capability and its associated Strategic Objectives, retained the active relationship count, updated the selected node, and populated the relationship editor with the filtered options.
